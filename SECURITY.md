## Reporting a Vulnerability

We take the security of **MooNsTransport** seriously.

**Do NOT report security vulnerabilities through public GitHub issues.**

To report a vulnerability:
1. Navigate to the repository's **Security** tab.
2. Click **Advisories** and select **Report a vulnerability**.
3. Detail the impact, attack vector, steps to reproduce, and any proposed mitigation.

Our team will investigate promptly and coordinate fixes before disclosure.
