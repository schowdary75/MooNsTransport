# Moon Android Scaffold

This folder documents the Android side of the Moon super-app.

Planned modules from the specification:
- Jetpack Compose home and route planner
- Map screen with live vehicle pins
- Booking and ticket flows
- Offline cache for saved routes and places
- FCM notifications and deep links

Suggested structure:
- `app/src/main/java/.../ui/`
- `app/src/main/java/.../data/`
- `app/src/main/java/.../domain/`
- `app/src/main/res/`

The web workspace uses the shared documentation surface and API contract to keep the native app aligned.
