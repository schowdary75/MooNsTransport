# Moon iOS Scaffold

This folder documents the iOS side of the Moon super-app.

Planned modules from the specification:
- SwiftUI home, search, and route planning
- MapKit map screen with station overlays
- Booking and ticket screens
- CoreData cache for offline usage
- APNs notifications and universal links

Suggested structure:
- `Moon/App/`
- `Moon/Features/`
- `Moon/Networking/`
- `Moon/Assets.xcassets/`

The documented routes and API contracts in the web workspace are intended to stay in sync with this native scaffold.
